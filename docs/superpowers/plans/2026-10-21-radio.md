# radio.zhoucai.me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Vite + React radio page at `radio.zhoucai.me` that streams 8 SomaFM channels in the "Radio in a window" design (D).

**Architecture:** A static single-page React app with no backend. `somafm.ts` holds the API calls and parsing, `usePlayer` owns one `<audio>` element and falls back to the next mirror, and the presentational components follow the D artboards. GitHub Actions builds the app and deploys it to Pages.

**Tech Stack:** Vite 8, React 19, TypeScript, Vitest 5 + @testing-library/react + jsdom, GitHub Pages (actions/deploy-pages).

**Spec:** `docs/superpowers/specs/2026-10-21-radio-design.md`. Visual reference: https://claude.ai/artifact/TJ1C3MicVzK2HJeWm3GVMG, artboards "D · Radio in a window" and "D · Radio in a window (phone)".

## Global Constraints

- Lineup, in order: `groovesalad, lush, bossa, dronezone, fluid, deepspaceone, folkfwd, secretagent`; dial labels `Groove, Lush, Bossa, Drone, Fluid, Space, Folk, Agent`.
- Endpoints: `https://somafm.com/channels.json`, `https://api.somafm.com/<id>.pls`, `https://somafm.com/songs/<id>.json`.
- Storage key `radio:v1` = `{ channelId, volume }`, defaults `groovesalad` / `0.7`; every access is wrapped in try/catch.
- Playback never autostarts.
- Tokens: sun `#fed377`, peach `#ffbb7a`, peach-ink `#a2541a`, cream `#fff3e6`, dial `#0f1a2b`, ink `#14212b`, ink-muted `#55636e`, hills `#bad578` / `#8fb021` / `#718d14`, dots `#ea8181` / `#f2d777` / `#6ed979`. Fonts: Figtree (body) and Jockey One (display, ≥28px only), from Google Fonts.
- Copy: buttons are lowercase (`play`, `pause`, `volume`); footer is "Music by SomaFM, listener-supported · donate" linking to `https://somafm.com/support/`.
- Error copy: "Can't reach the radio right now" (with a `try again` button) and "This station's quiet — try another".
- Every control is at least 44px and has a 3px focus ring in `#2b78a8`; all motion is off under `prefers-reduced-motion`.
- Commits use Conventional Commits with no Claude attribution lines.

## Review Focus

1. **Rapid station switching:** a slow `.pls` fetch for an old station must never start playing after a newer one was picked. Tested in Task 3.
2. **Space key on a focused button:** pressing it must toggle playback once, not twice (button click plus global handler). Tested in Task 5.
3. **Stored channel no longer in the lineup:** a stale or garbage `channelId` falls back to `groovesalad`. Tested in Task 2.
4. **`audio.play()` rejects** (autoplay policy or network): the status becomes `error` or paused, with no unhandled rejection and no stuck "loading". Tested in Task 3.
5. **Now-playing after a switch:** polling for the old station stops, and its stale result never shows under the new station. Tested in Task 4.

### Task 2: SomaFM client and stored state

**Files:**
- Create: `src/somafm.ts`, `src/somafm.test.ts`, `src/storage.ts`, `src/storage.test.ts`

**Interfaces:**
- Produces:
  - `type Channel = { id: string; short: string; title: string; description: string; listeners: number; genre: string }`
  - `type Track = { artist: string; title: string }`
  - `LINEUP: ReadonlyArray<{ id: string; short: string }>`
  - `parsePls(text: string): string[]`
  - `toChannels(json: unknown): Channel[]`
  - `parseSongs(json: unknown): Track[]`
  - `fetchChannels(): Promise<Channel[]>`
  - `fetchStreams(id: string): Promise<string[]>`
  - `fetchSongs(id: string, signal?: AbortSignal): Promise<Track[]>`
  - `type Stored = { channelId: string; volume: number }`
  - `loadStored(storage?: Storage): Stored`
  - `saveStored(s: Stored, storage?: Storage): void`

- [ ] **Step 1: Write the failing tests**
  - `parsePls` returns the `File1..3` URLs, ordered by number, from the real Groove Salad `.pls` text (spec, Data source). Lines in any order are sorted by number, and text with no `File` lines returns `[]`.
  - `toChannels` takes `{channels:[…]}` with lineup ids shuffled plus one extra id, and returns lineup order with the extra dropped. A lineup id missing from the input is skipped. `listeners` is a number (it's a string in the source JSON). `short` comes from `LINEUP`.
  - `parseSongs`: `{songs:[{artist:'The Album Leaf',title:'New Soul'}]}` gives one track. `{}`, `null` and `{songs:'x'}` each give `[]`.
  - `loadStored`: with no storage it returns the defaults. Corrupt JSON returns the defaults. A `channelId` not in `LINEUP` resets to `groovesalad`, keeping the stored volume. A volume outside 0–1 resets to `0.7`. A storage whose `getItem` throws returns the defaults. A `saveStored` whose `setItem` throws does not throw.
- [ ] **Step 2:** Run `npx vitest run src/somafm.test.ts src/storage.test.ts`. Expected: FAIL (module not found).
- [ ] **Step 3:** Implement the functions in `src/somafm.ts` and `src/storage.ts`. The fetch wrappers throw on a non-2xx response.
- [ ] **Step 4:** Run the same command. Expected: PASS.

- [ ] **Step 1: Write the failing tests**, using `renderHook` with a fake audio element (an EventTarget with `src`, `volume`, and a `play` mock that you resolve or reject):
  - `play('lush')` sets `src` to the first mirror and moves the status from `loading` to `playing` on the `playing` event.
  - An `error` event moves to mirror 2, then mirror 3. An error on the last mirror sets the status to `error`.

  - `pause()` sets the status to `idle` and calls `audio.pause()`. `setVolume(0.3)` sets `audio.volume` to 0.3.
